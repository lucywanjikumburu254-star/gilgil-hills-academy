# Gilgil Hills Academy

A responsive school website built with Next.js for Gilgil Hills Academy, Gilgil, Nakuru County, Kenya.

## Brand palette

- Primary grey: #55585C
- Deep charcoal: #33363A
- Accent red: #B71C1C
- Highlight yellow: #FBC02D
- White: #FFFFFF

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

## School photography

Add public Cloudinary delivery URLs to the environment variables listed in \`.env.example\`. These are public image URLs, not API credentials. Do not expose the Cloudinary API Secret in browser code or commit it to GitHub.

## Important content checks

Confirm the current enrolment figure, years of operation, school sections, approved results claims, fees, and admissions requirements before publishing those claims.
